# Todo List API

Todo List API — это REST-сервис для управления задачами, созданный с упором на правильную архитектуру и безопасность. Проект включает в себя авторизацию (JWT), систему категорий и тегов, а также полностью задокументирован через Swagger. Проект написан с соблюдением стандартов PEP 8 и покрыт Unit-тестами.

## 🚀 Основные возможности
* **Регистрация и JWT-авторизация**
* **Управление задачами (CRUD)**
* **Категории и метки**
* **Поиск и фильтрация**
* **Пагинация**
* **Автоматическая документация (Swagger)**
* **Покрытие Unit и интеграционными тестами**

## 🛠 Стек технологий
* **Python 3.13+**
* **Django 6.0+**
* **Django REST Framework 3.17+**
* **Simple JWT 5.5+**
* **django-filter 25.2+**
* **drf-spectacular 0.29+**

## 📦 Установка и запуск

1. **Клонировать репозиторий**
    ```bash
   git clone https://github.com/Omenn6/todo-django-rest.git
   cd todo-django-rest
   ```
   
2. **Настроить окружение**

* **Создать виртуальное окружение**
    ```bash
   python -m venv venv
   ```

* **Активация для Windows**
    ```bash
   source .venv\Scripts\activate\
   ```

* **Активация для Linux/macOS**
    ```bash
   source .venv/bin/activate
   ```
   
3. **Установить зависимости**
    ```bash
   pip install -r requirements.txt
   ```
   
4. **Выполнить миграции**
    ```bash
   python manage.py migrate
   ```
   
5. **Запустить сервер**
    ```bash
   python manage.py runserver
   ```
